# 广轻活动汇总 Edge v3.8

Windows 可运行版发布目录。

## 运行

打开 `广轻活动汇总-Edge/广轻活动汇总-Edge.exe`。

程序依赖系统已安装的 Microsoft Edge WebView2 Runtime。登录和活动页面均使用学校活动系统的正常网页界面。

## 内容

- `广轻活动汇总-Edge/`：完整的 Windows 可运行目录，必须保留 `_internal` 子目录。
- `SHA256SUMS.txt`：主程序的 SHA-256 校验值。

## 使用边界

程序仅执行用户发起的页面浏览和单次报名操作；不包含批量请求、循环重试、绕过验证码或规避学校系统限制的功能。
